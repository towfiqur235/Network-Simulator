Guide

🧪 Demo Simulation

A fixed PC↔Switch↔Router×3↔PC network. Configure the message and protocols, hit Send, then use Play/Step/Replay to walk through every layer.

🗺️ Topology Builder

Drag devices from the palette onto the canvas, or click a template to insert one (templates stack — they don't replace what's already there). Use Connect Mode to wire devices, then set a Sender and Receiver and press Start Simulation.

📶 Line Encoding Lab

Pick any scheme to see its waveform and theory, or switch to Comparison Mode to see several schemes side by side against the same bit stream.

🧩 Framing Lab

Byte stuffing escapes FLAG/ESC bytes inside your message; bit stuffing inserts a 0 after every five consecutive 1s so the 01111110 flag pattern never appears inside data.

🛡️ Error Detection

Enter data bits and a generator polynomial to see the CRC computed via binary (XOR) division, then inject a transmission error and watch the check fail.

🩹 Error Correction

Hamming(7,4) encodes 4 data bits with 3 parity bits. Flip any one bit and the syndrome calculation will locate and auto-correct it.

📊 Performance Dashboard

Every run in Demo or Builder mode updates these live counters — packets sent/delivered/dropped, retransmissions, and success rate.

📄 Reports

Fill in your details and generate a print-ready lab report that includes the log from your last simulation — use your browser's "Save as PDF" option in the print dialog.
